# ПЖ-19 - Интернет кооператив

Веб-приложение для потребительского интернет кооператива «ПЖ-19», реализованное на React + Next.js.

## Технологии

- **Next.js 14** - React фреймворк
- **TypeScript** - типизация
- **React 18** - UI библиотека

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Сборка для продакшена

```bash
npm run build
npm start
```

## Структура проекта

```
├── app/                    # Страницы Next.js (App Router)
│   ├── layout.tsx         # Корневой layout
│   ├── page.tsx           # Главная страница
│   ├── login/             # Страница входа
│   └── application/       # Страница заявки
├── components/            # React компоненты
│   ├── Header.tsx         # Шапка сайта
│   ├── Footer.tsx         # Подвал сайта
│   ├── TariffsSection.tsx # Секция тарифов
│   ├── AddressCheckSection.tsx # Проверка адреса
│   ├── CooperativeSection.tsx  # О кооперативе
│   ├── ContactSection.tsx      # Контакты
│   ├── LoginForm.tsx           # Форма входа
│   └── ApplicationForm.tsx    # Форма заявки
├── styles/                # Стили
│   └── globals.css        # Глобальные стили
└── public/                # Статические файлы
    └── logo.png           # Логотип
```

## Функциональность

- ✅ Главная страница с тарифами и услугами
- ✅ Проверка возможности подключения по адресу (с интеграцией Yandex Maps)
- ✅ Информация о кооперативе
- ✅ Страница входа в личный кабинет (телефон, договор, Telegram, email)
- ✅ Страница подачи заявки на подключение
- ✅ Адаптивный дизайн для всех устройств

## Деплой

Проект готов к деплою на Vercel, Netlify или любой другой платформе, поддерживающей Next.js.
